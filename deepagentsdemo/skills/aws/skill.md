# AWS Skill

## Purpose

This skill handles AWS-related tasks.

Supported Services:

- EC2
- ECS
- EKS
- Lambda
- S3
- DynamoDB
- RDS
- Bedrock

- User mentions AWS.
- User needs infrastructure.
- User requests architecture diagrams.

3. Cost estimate
4. Security considerations
5. Best practices
