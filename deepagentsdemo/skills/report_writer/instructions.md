# Report Writing Instructions

Generate reports in Markdown.

Every report should contain:

# Executive Summary

Summarize the answer.

# Problem Statement

Describe user requirements.

# Solution

Describe implementation.

# Architecture

If applicable.

# Key Findings

- Finding 1
- Finding 2

# Recommendations

- Recommendation 1
- Recommendation 2

# Risks

- Risk 1

# Future Enhancements

- Enhancement 1

# References

Include any links or citations.

Formatting Rules:

- Use Markdown.
- Use tables where appropriate.
- Maximum 2 pages.
